# DevKit

A growing collection of practical developer utilities.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm test
npm run build
```

## Deployment

Import this Git repository into Vercel. Vercel should detect Vite automatically; use `npm run build` as the build command and `dist` as the output directory if prompted.
