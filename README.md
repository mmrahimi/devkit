# DevKit

*A collection of practical tools built to make developers' everyday workflows easier.*

## Tech Stack

- React
- TypeScript
- Vite

## Getting Started

### Requirements

- Node.js 20.19+ or 22.12+
- npm

### Installation

Clone the repository and install dependencies:

```bash
git clone <repository-url>
cd devkit
npm install
```

### Development

Start the local development server:

```bash
npm run dev
```

### Checks

Run the test suite and production build:

```bash
npm test
npm run build
```

## Deployment

DevKit can be deployed through [Vercel](https://vercel.com).

Import the Git repository and configure:

- **Framework Preset:** Vite
- **Build Command:** `npm run build`
- **Output Directory:** `dist`
